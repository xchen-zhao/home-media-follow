# Home Media Follow

> **技术预览候选 v0.1.0-alpha.2。** 已实机验证 Windows 独立安装、定时追更、从网盘已有文件下载并入库 Jellyfin，以及删集不补回。真实分享转存仍缺少成功回执，本轮同账号自测返回 `errno=2`。首次扫码授权、云端同集换版和整机重启恢复仍待验证。[验收报告](docs/verification.md)

在 Windows 电脑上运行的家庭影音追更后台。它扫描已登记的来源，按订阅起点发现新集，经本人网盘、OpenList 和 aria2 下载到本地，再交给 Jellyfin 索引和验证。

项目从旧笔记本的实际部署中整理而来。后台独立运行，不需要 Mac 在线、保留聊天或持续调用 AI。首版面向愿意配置 Windows 任务计划程序、网盘授权和本机服务的用户。

## 工作方式

```text
已登记来源 → 识别作品／季／集／上下 → 转存本人网盘 → 探测实际画质
          → OpenList 下载入口 → aria2 → 校验与归档 → Jellyfin 验证
```

- 每小时发现新集，每15分钟恢复下载、入库和到期画质检查，开机后2分钟补查。失败重试受退避约束。
- 云库存与本地下载请求分开。首次只取最新逻辑集，之后追订阅起点及其后的新集；云端历史清单不会触发本地全集下载。
- 最低1080p，优先更高分辨率。采用探测结果，不采信文件名中的“4K”。合格回退版可以在确认更高档位后安全升级。
- 旧集由用户在 Jellyfin 手动删除。受管已完成剧集消失后，后台记录该逻辑集不补回；新集继续追更。
- 转存、下载与替换都有持久回执。操作结果不明时先对账，重试沿用原请求身份。
- 下载结束与完成入库是两个状态。完成要求文件验证与 Jellyfin 有限播放探针通过，不等于整片观看验收。

## 支持范围

运行目标为 Windows 与 Python 3.13 或更新版本。核心使用 Python 标准库，另需自行安装 OpenList、aria2、Jellyfin 和 ffprobe。配置中的服务地址仅允许本机回环 HTTP 地址。Linux、NAS、Docker 和 macOS 常驻部署不在首版支持范围；可在其他系统运行不依赖 Windows 的单元测试。

静态登记来源是默认模式；印象笔记目录集成属于可选适配器。电影、精确指定集恢复、自动删旧和任意来源搜索不属于当前命令能力。Hermes、Telegram 与 AI Skill 不是必需组件。

## 开始使用

在项目根目录打开 PowerShell，创建独立 Python 环境并安装：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .
.\.venv\Scripts\python.exe -m home_media_follow --root C:\HomeMediaFollow init
.\.venv\Scripts\python.exe -m home_media_follow --root C:\HomeMediaFollow check
```

`init` 仅接受空目录，不会接管旧部署，也不会自动激活作品。`--root` 放在子命令之前。接着按[安装与首次运行](docs/installation.md)配置外部服务、授权和来源，再提交订阅。不要把已有家庭服务目录直接当作测试实例根目录。

## 当前验证边界

当前候选版本尚未完成真实跨账号分享转存成功验收：自有分享向同账号转存返回 `errno=2`，没有成功回执，具体原因未确认。复用原生复制到专用云端目录的生成视频可以继续验证下载与入库，不能替代成功转存，也不能据此宣称全部发布门槛已通过，详见[验收边界](docs/testing.md#当前真实转存验收缺口)。

旧部署的运行记录说明方案有实际使用基础，不能替代本仓库新版本的安装与验收。本仓库的验证结果以发布时随附的测试报告及版本摘要为准；尚未执行的真实授权、转存、开机触发或播放场景应明确标为未验收。模拟服务测试不能证明网盘当前可用。

网盘网页接口及授权方式可能变化。项目不承诺下载速度、资源可用性或第三方服务持续兼容。示例与测试只使用自有生成视频，不附影视文件、真实分享或提取码。
