2. 与成功转存及托管归属相关的真实云端换版事务，尚未完整实测。已有云端文件的原生复制准备和下载验证不授予自动退休这些文件的权利。
3. 实际整机重启、开机触发执行和重启后恢复未测试。本轮只核对了开机2分钟定义及程序恢复测试，没有重启家庭设备。
4. 本轮复用了已授权的 Windows 本机会话，未重跑手机扫码登录。

真实来源扫描、下载和入库测试先通过原生同账号复制准备专用云端文件，然后复用这些文件。它验证了真实接口与下载发布链路，但**不能替代成功转存验收**。保留上述缺口，避免将当前候选版标成全部门槛通过。
