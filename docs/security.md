# 安全与公开资料边界

实例目录与源码仓库分开。源码、文档与虚构配置可以提交；真实状态、来源绑定、分享提取码、签名下载地址和账号资料应留在目标电脑。

## 本机凭据

服务凭据使用实例专属 Windows DPAPI 文件。密文文件本身也不能提交仓库；DPAPI不是替代文件访问控制的措施。计划任务运行账户只应有代码与配置读取权限、状态和暂存目录写入权限，避免让日常交互账户任意改写后台状态或秘密文件。

授权在目标 Windows 的本机交互终端完成；服务密码通过隐藏提示输入，百度默认打开专用 Edge 的官方二维码登录，不提供命令行秘密参数。专用登录 profile 与二维码按秘密目录同样保护，未完成实际服务账户核验前保留，不公开登录后的账户页面。不要经 SSH stdin、issue、聊天或日志转交秘密；也不要从其他电脑导出已有会话供本项目使用。

Jellyfin、OpenList、aria2 的控制地址限制为回环地址。程序不会把它们的账号或令牌带到重定向的外部地址。若需要远程维护，应使用受信任的系统通道，不把控制端口直接放到公网。

## 日志与错误

错误信息应保持可定位的服务名、阶段和状态码，不输出上游响应全文、Cookie、提取码或签名 URL。状态清单也可能包含作品偏好、网盘文件 ID 和本地目录，因此日常报告不能未经检查直接上传。

报告问题时只提交版本、脱敏错误类型、对应阶段及最小复现步骤。用生成视频重现；不要上传影视原片、真实分享清单、私有回执或整个实例目录。

## 发布前检查

扫描候选源码、测试、构建产物与 Git 全部历史。检查账号秘密、真实分享、家庭账号、机器人或聊天标识、设备地址及个人绝对路径。`.gitignore` 只能阻止部分误提交，不能清除已经进入历史的秘密。

如果发现泄露，先停止发布并撤销相应凭据，再处理历史与重建发布包。只删除当前文件不能消除旧提交中的内容。

首版使用自有生成视频建立专用测试分享。真实测试结束后撤销测试分享，仅依据精确测试回执清理自建资源，不操作生产订阅、媒体或云端历史。
