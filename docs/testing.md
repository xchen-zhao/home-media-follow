# 测试与发布验收

测试目标是证明公开包可以独立运行，且不会扩大下载或删除范围。已有家庭部署的成功记录只作为背景，本仓库以自身版本摘要对应的验收记录为准。

## 本地回归

在项目根目录执行：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试应覆盖集数与上下解析、来源范围、候选选择、订阅起点、小时去重、失败退避、重复请求、转存对账、下载契约、发布事务、Jellyfin有限播放探针及删集不补回。

故障场景至少包含不完整分页、身份或路径冲突、认证失效、限流、结果未知、磁盘不可访问、磁盘不足、换版中断、状态恢复和同集升级取消。未知结果不等于失败，不能靠清状态或另造 ID 让测试通过。

## 生成媒体与隔离服务

使用 ffmpeg 生成短视频，例如：

```powershell
ffmpeg -f lavfi -i testsrc2=size=1920x1080:rate=24 -t 3 -c:v libx264 -pix_fmt yuv420p example-1080p.mp4
ffmpeg -f lavfi -i testsrc2=size=3840x2160:rate=24 -t 3 -c:v libx264 -pix_fmt yuv420p example-4k.mp4
```

视频只用于测试，不打包进源码。将测试系列分成明确季数、集数和上下文件；低画质等待用独立720p样本。为测试创建独立 OpenList、aria2、Jellyfin 实例和端口，Jellyfin测试库分别读取测试 `media_root` 下的 `动漫`、`电视剧`、`综艺` 分类目录（内容类型为电视剧），不能把分类父目录当作系列库根。先检查端口是否占用；不能通过停止现有家庭服务取得端口。

## 真实链路

仅在已获得对应账号和资源操作授权的环境执行。创建专用网盘目录，上传生成视频并建立自测分享；凭据只留在目标 Windows。验证真实分享读取、转存、OpenList访问、aria2下载、归档、Jellyfin条目完整路径和有限原文件播放探针。

分别验证首次最新集、下一新集、同期后发下集、跨季过滤、合格回退后升级、手动删集不补回、服务重启后的恢复，以及重试不产生重复下载。自有分享若被上游禁止向同账号转存，应记录真实限制，不能用模拟转存冒充真实通过。

## Windows 与任务计划程序

检查实际运行账号、目录 ACL、凭据读取边界、每小时和每15分钟触发器、开机2分钟触发器、防重入、失败后补跑、暂停恢复与卸载。任务定义正确不等于实际开机触发通过；未经授权不重启家庭设备，未实测场景保留为未验收。

## 发布门槛

- 从发布包在全新隔离目录照文档安装，不借用私人历史文件或旧发布脚本。
- 必要自动测试通过，真实端到端报告绑定准确版本；列明模拟、接口实测和播放探针的边界。
- 独立评审无发布阻塞问题，来源、许可证、秘密扫描及 Git 历史检查完成。
- 测试分享撤销，测试资源按精确回执清理，现有家庭部署未因测试改变。
- 发布包、校验摘要、测试报告和已知限制一致。

尚未完成的真实测试不能标为通过。必要条件因账号、接口或设备限制而缺失时，报告应阻止宣称完整发布就绪，并保留可复查的脱敏证据。

## 当前真实转存验收缺口

当前候选版本的自有分享向同账号转存测试未取得成功回执，返回 `errno=2`，已按结果未知保留对账；该错误的具体原因尚未确认。本轮没有成功重跑跨账号分享转存，因此不能报告该项通过，也不能据已有部署历史宣称全部发布门槛已经满足。

先通过原生复制将生成视频放入专用云端测试目录，再复用已有云端文件执行来源扫描、OpenList访问、aria2下载和Jellyfin验证，可以检查真实下载与入库链路，但不能代替成功转存验收。模拟转存结果同样不能补足这一缺口。完整发布就绪结论必须保留该阻塞，直到对应公开版本取得真实成功回执。


## 打包与公开内容检查

```powershell
python -m pip install build
python -m build
python tools/verify_release.py
gitleaks dir . --redact --max-archive-depth 2
gitleaks git . --redact
```

Gitleaks 通过官方发行物独立安装，不是运行时依赖。自带检查器用于语法、基础私人路径和许可证打包检查，不代替秘密扫描及人工核对。Git历史扫描应在本地提交后运行；公开仓库之外的原始运维证据不进入发行物。
