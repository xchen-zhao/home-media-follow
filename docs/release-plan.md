# 首版开源实施与验收计划

首版在独立目录整理 Windows＋Python 3.13 的追更后台、中文文档、CLI、配置示例与任务工具；核心不依赖 Mac、AI 或 Telegram。实施阶段交付本地候选包。GitHub 技术预览沿用该候选的运行逻辑，并随包说明实测范围和已知限制。下表适用于完整自动追更正式版。

## 实施顺序

1. 按白名单提取源码与测试，排除历史来源、凭据、状态、备份和媒体；核对引用来源与许可证。
2. 去除旧发布脚本与私人清单依赖，配置化路径和回环服务地址，补齐独立发布、初始化、本机授权和来源检查。
3. 保留云库存/本地请求分离、订阅起点、跨季过滤、删集不补回、画质探测和可恢复换版；控制请求持久排序并幂等处理。
4. 在 Mac 和隔离 Windows 上测试；使用生成视频、自测分享及独立服务、任务、媒体库验证实际行为。
5. 独立评审安装权限、路径安全、请求恢复、数据范围、打包和文档；冻结源码摘要后复测修复项。
6. 重新安装发行 wheel，验证代码与安装包一致；扫描源码、归档与 Git 历史，生成校验摘要及验收报告。
7. 撤销测试分享，清理精确归属的云端与本机测试资源；复核现有部署配置及订阅控制未被测试改变。

## 发布门槛

| 门槛 | 必须具备的证据 |
|---|---|
| 独立安装 | 脱离开发目录运行 wheel 的初始化、检查、后台与状态入口 |
| 行为可靠 | 当前源码回归，以及真实下载、入库、删集防补回等实测 |
| 云端转存 | 对应公开版本的真实成功转存与后续入库回执 |
| 权限边界 | LOCAL SERVICE 正常运行、非授权身份拒读凭据、重解析路径拒绝 |
| 可维护 | 任务安装、暂停、恢复、卸载；故障与恢复说明 |
| 可公开 | 许可证和来源明确，秘密及私人标识扫描通过，独立评审无未解决阻塞 |
| 可追溯 | 源码摘要、测试环境、模拟/实测边界、包摘要与未完成项一致 |

当前结果见[验收报告](verification.md)。尚未通过的门槛不因模拟测试或历史部署记录而改为通过。实际开机触发与整机重启恢复若未执行，保持为未验收；本轮不重启家庭设备。
